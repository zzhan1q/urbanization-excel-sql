# Рост доли городского населения

В Турции доля городского населения выросла с 69,35% в 2010 году до 89,02% в 2023-м. Камбоджа прибавила почти столько же: 19,51 п. п., хотя её итоговая доля осталась ниже половины. В сравнении 217 экономик с данными за оба года.

[Книга Excel](report.xlsx) · [Запрос SQLite](analysis.sql) · [Результаты CSV](summary.csv)

SQL соединяет два года по стране и показателю. Excel вычитает начальную долю из конечной. Лист «Сверка» показывает пропуски по году и расхождения между формулами и SQL.

Доля городского населения зависит от национального определения города. Рост доли не означает, что абсолютное сельское население уменьшилось.

**Источник.** Всемирный банк, World Development Indicators: [`SP.URB.TOTL.IN.ZS`](https://data.worldbank.org/indicator/SP.URB.TOTL.IN.ZS). В `source.csv` оставлены национальные ряды за 2010–2023 годы; региональные и глобальные агрегаты исключены. [Лицензия набора](https://datacatalog.worldbank.org/infrastructure-data/search/dataset/0037712/world-development-indicators). Дата выгрузки: 23 ноября 2026 года. Пустая ячейка означает отсутствие наблюдения.
